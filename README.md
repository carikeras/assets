# CariKeras Assets

Shared public brand assets for the CariKeras ecosystem.

## CDN

Production services can consume versioned assets through jsDelivr:

https://cdn.jsdelivr.net/gh/carikeras/assets@latest/brand/carikeras-mark.svg

Pin a tag or commit once a stable release is published.
